# todo-spa

TODO SPA with Redux state management and action session recording/replay.

Originally built in 2019/2020 with Webpack 4, Babel, and JavaScript ([original repository](https://github.com/lucastlima/todo-spa)), migrated to Vite and TypeScript.

## Development Mode
`npm run dev` - Start Vite dev server.

## Production Build
`npm run build` - Typecheck and build static bundle into `dist/` (ready for Cloudflare Pages).

## Preview Build
`npm run preview` - Preview production build locally.

## Tests
`npm test` - Run tests with Vitest.
